# 🐍 Python Full Stack – Flask

> **Repository:** PFS-VSP-004-Flask
> **Duration:** 35 Days
> **Focus:** Python, Flask, MySQL, REST APIs, React Integration & Deployment

## 📌 About This Repository

This repository contains my **35-day Python Full Stack development journey with Flask**.

It includes daily class notes, practice programs, assignments, mini-projects, and a major industry-level project.

The goal of this repository is to learn Flask from the fundamentals and gradually move towards building and deploying complete web applications.
