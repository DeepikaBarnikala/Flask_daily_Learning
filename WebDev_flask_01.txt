Web Development:
=================
It refers to the overall process of creating, building and maintain web applications or websitesit encompasses everything 
from plain text web pages to complex networks, e-commerce platformand real time web applications

Broadly divided into two disciplines
	-> Frontend Development (Client Side) -> Focus on visual presentations, layouts and user interactivity using 
	   	HTML5,CSS3,JS (React) UI
	-> Backend Development (Server Side) ->  It focuses on core bussiness logic, user authentication, database
		operations and APIs using Language such as Python,Java,Node,PHP

(i) Full Stack Development:
===========================
It refers to the practice of working both on the frontend and backend of a web application. A FullStack Developer
posses the skills required to design a complete web application from scratch -> managing responsive user interfaces 
to managing server logic,writing database queries and deploying applications to production servers

Flask Advantages vs Disadvantages
================================== 

HTTP vs HTTPs
=============
HTTPs-->HTTPs is HTTP with Security through encryption

HTTP(Unsecured) -->Not Encrypted Best Suited for Local offline demos
-->Security risk is higher-->Data can be intercepted and exposed
-->Default port :80

HTTPs(Secured) -->Encrypted  via SSL and TSL
-->Best Suited for all real public websites ,data is protected
-->Default port:443


Request Response Cycle -->Flask
================================
Step1: Browser(User Initialise the action)

Step2: HTTP Request(Data sent to server)

Step3: Flask Route('/')(matches the url path)

Step4: Python Functions(Triggers mapped code)

Step5: Bussiness Logic (Process the Request)

Step6: HTTP Response (Formulate the answer back)

Step7: Browser(Render the Webpage)
